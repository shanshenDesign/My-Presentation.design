# Example Prompt — copy, fill, paste to your AI agent

## Routed (let the system choose)

> Build a landing page for **[your product]**, used by **[audience]**.
> Tone: **[e.g. calm / rebellious / luxurious]**. Energy: **[0–10]**. Formality: **[0–10]**.
> Content density: **[minimal / balanced / rich]**. Medium: **[website / web app / poster / social]**.
> Brand constraints: **[colors/fonts that must survive, or "none"]**.
>
> Follow `AGENT.md` and `design-system/routing.md`. Route to one style from
> `design-system/style-index.yaml`, apply it as law, pass
> `design-system/accessibility.yaml`, and self-check with `design-system/quality-bar.md`
> before delivering. Declare your style + rationale in the commit message.

## Directed (you choose the style)

> Build **[thing]** for **[audience]**. Use
> `design-system/styles/photorealistic-collage.yaml` as binding law.
> Follow `AGENT.md`, `core.md`, `accessibility.yaml`, and `quality-bar.md`.
> Real content only — no placeholders, no dead buttons. Mobile-first, flawless at 360px.

## Tips for mind-blowing results

- **Name the wow moment** you want: "the hero should feel like walking into a gallery" beats "make it nice".
- **Give real content** (or realistic fake content). Styles collapse around lorem ipsum.
- **One style is a statement; two is a remix; three is a mess.** Trust the routing.
- Ask the agent to state its style + rationale — if the rationale is weak, the build will be too.
